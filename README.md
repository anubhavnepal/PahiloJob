# Pahilo Job

A static, multi-page front-end mockup for a job-listing site ("Pahilo Job" — Nepali for "first job"). No backend or API calls; it's HTML/CSS pages styled with Bootstrap.

## Tech stack

- HTML5, Bootstrap 5 (via CDN), Font Awesome (via CDN)
- SCSS source (`style.scss`) compiled to `style.css`

## Pages

- `index.html` — job listing / "Find Job" page
- `company.html` — company page
- `roadmap.html` — roadmap page
- `profile.html` — profile page

## Setup

This is a static site with no build step or dependencies. Open `index.html` directly in a browser, or serve the folder with any static file server, e.g.:
```
npx serve .
```
